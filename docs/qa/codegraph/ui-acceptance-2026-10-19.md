## Functional evidence

The modes script confirms selected real symbols survive applicable view changes;
impact defaults to two hops and expands the original focus radius, preserving
original source→target evidence paths and shortest distances across pages.
Hierarchy uses child→parent/class→interface direction with extends solid and
implements dashed; non-types and the actual TypeScript interface-extends SDK
limitation are explicit.

Dependencies replace cumulative aggregate pages. Their declared count metric,
unique-site total, verified cycle membership, real edge evidence, unresolved
coverage and terminal budgets are explained. Aggregate nodes never request
fabricated source. Evidence resolves a real node, then requests its sourceLine;
same-file evidence can change the displayed snippet and immutable location link.

Clusters start at a bounded directory overview, drill to files and true symbols,
and retain incoming/outgoing boundary groups. Breadcrumbs, Back and Collapse
support keyboard navigation. Repeating a scope is idempotent. Scope transitions
retain the live canvas/camera and reuse bounded cached coordinates. Budget
remainders are labeled collapsed placeholders with no looping drill/source
operation. `distinctSiteCount` is used to reconcile layers; edge counts are not
summed as a unique-site total.

The live chain used a temporary committed Git repository with 7 files, 23 nodes
and 34 indexed edges. All five modes, real TypeScript/JavaScript calls, impact
paths, inheritance, alpha/beta cycles, cluster boundaries/drilldown and real

`e5e10246f4e0fbdad9a07cb74018def1`. There were 13 graph and 9 source requests.

## Frontend first-graph performance

The source payload is an **actual structured adapter response from a synthetic
SQLite benchmark with 5,000 nodes and 15,000 edges**, returning 100 nodes and
300 edges. It is not a graph generated by the SDK parser. Browser interception
remaps asset/version/node identities for the isolated UI fixture and removes its
opaque continuation. This measurement excludes backend extraction/network time;
the live HTTP chain above is separate evidence.

Measurement starts at browser ResourceTiming `responseEnd` and ends after an
actual canvas node hit updates its detail title (`mod5.n85`) plus two animation
frames. Playwright click latency is included. "Cold" means the first graph mount

## Limits

The current SDK does not extract TypeScript interface inheritance or all star
re-exports. The UI reports these limits; a completed index scan does not imply
complete source dependency extraction. Static potential impact does not claim
runtime failure. Same-source snapshot hashes, source budgets and ACL behavior
are tested by the backend suites; the local live browser uses fixture identity
and ACL. Existing Tea forwardRef/findDOMNode development warnings were observed,
with no new graph exception.
